# 캡컷 에이전트

한국어 토킹 영상(mp4/mov)을 올리면 **무음·잔말·NG 컷, 자막, 훅, 줌, 강조 팝업, 챕터, 음량 보정까지 적용된 완성 mp4**를 자동으로 만드는 로컬 웹 도구입니다. **캡컷은 필요 없습니다**(원하면 같은 편집이 담긴 캡컷 드래프트도 함께 만듭니다).
[pycapcut](https://github.com/GuanYixuan/pyJianYingDraft) 으로 드래프트를 만들고, FastAPI + 정적 HTML 1장으로 동작합니다.

## 실행
```bash
cd capcut-agent
pip install -r requirements.txt     # + ffmpeg 필요: brew install ffmpeg / winget install ffmpeg
python -m capcut_agent.server       # → http://127.0.0.1:8765
```
- Mac M칩(트랙 A): `pip install mlx-whisper` 하면 자동으로 mlx-whisper 사용, 그 외는 faster-whisper.
- 환경변수: `CAPCUT_DRAFT_DIR`(드래프트 폴더 강제 지정), `CAPCUT_WORKDIR`, `PORT`, `CAPCUT_MIN_STAGE`.
- CapCut 드래프트 폴더를 못 찾으면 `workspace/output/` 에 저장됩니다(CapCut 설치+1회 실행 후 자동 인식).

## 완전 자동 (v0.3)
1. 영상을 올린다 → 2. 워크플로(숏폼/롱폼/강의)를 고른다 → 3. 기다린다 → **완성 mp4 다운로드**.
- 결과 화면에서 포인트를 끄거나 켜면 완성 영상을 **자동으로 다시 렌더링**합니다(진행률 표시).
- 숏츠 후보는 버튼 한 번으로 **9:16 mp4**까지 만들어집니다.
- 렌더링은 ffmpeg로 하며 자막은 ASS(libass)로 입힙니다. 한글 폰트는 Mac `Apple SD Gothic Neo`, Windows `Malgun Gothic`을 쓰고, Linux는 설치된 한글 폰트를 찾습니다. 다른 폰트는 `CAPCUT_FONT="폰트이름"`으로 지정하세요.
- 렌더링 없이 캡컷 드래프트만 원하면 옵션에서 "완성 mp4 자동 렌더링"을 끄세요.
- 출력 위치: `workspace/output/`

## 작업 관리 (v0.4)
- **서버를 껐다 켜도 작업이 남습니다.** 첫 화면의 *최근 작업*에서 다시 열고, 중단된 작업은 *다시 시도*로 이어서 처리합니다.
- 분석은 한 번에 **1건씩**(`CAPCUT_JOBS`로 변경), 나머지는 순번대로 대기합니다. 대기·진행 중에도 **취소**할 수 있습니다.
- **저장 공간**을 표시하고, 오래된 작업(기본 30일)은 확인 후 수동으로 정리합니다. 삭제하면 원본 복사본·완성 mp4·캡컷 드래프트가 모두 지워집니다.

## 대본으로 편집하기 (v0.4)
결과 화면 맨 아래 **대본**에서:
- **단어 클릭** = 그 지점으로 이동
- **드래그해서 선택 → 삭제** = 그 구간을 컷으로 제거 (컷 목록에 *직접*으로 표시, 클릭하면 되살림)
- **단어 더블클릭** = 글자 수정 (자막·팝업에 반영, 비우면 자막에서 제외, 원래 글자로 쓰면 되돌림)
- 고친 뒤 **드래프트 갱신**을 누르면 음성 인식 없이 완성 영상이 다시 만들어집니다.
- 렌더 mp4에는 **음질 보정**(노이즈 제거 + -16 LUFS 라우드니스)이 적용됩니다.

## 핵심 원칙
1. **전체 대본을 먼저 추출 → 그걸로 NG/자막 결정** (단어 단위 판단 X). 같은 문장이 다시 나오면 앞 테이크를 NG로, 마지막 테이크를 유지.
2. **검증 = 사용자가 캡컷에서 직접 재생.** 빌드 성공 ≠ 검증. 웹 프리뷰는 사전 확인용입니다.
3. ASR은 `asyncio.Lock`으로 직렬화, 캐시는 mtime이 아닌 **content hash**.

## 워크플로 × 편집 포인트 (v0.2)
업로드 시 워크플로를 고르면 아래 편집 포인트가 자동으로 켜지고, 결과 화면의 **편집 포인트 탭**에서 개별로 끄고 켤 수 있습니다(ASR 재실행 없이 드래프트만 재생성).

| 편집 포인트 | 자동 편집 | 숏폼 | 롱폼 | 강의 |
|---|---|:-:|:-:|:-:|
| 오프닝 훅 | 가장 강한 문장(질문·숫자·훅 단어·목소리↑)을 앞에 티저로 배치 | O | O | - |
| 리듬 줌 | 문장 경계에서 100%↔확대 교차(숏폼 115%, 롱폼 108%), 단어 중간은 안 자름 | O | O | - |
| 강조 팝업 | 숫자·핵심어를 음량 피크와 결합해 선별, 밀도·반복 제어, 등장 애니메이션 | O | O | O |
| 챕터 | 전환어·긴 휴지·주제어 변화로 감지 → 타이틀 카드 + **유튜브 챕터 텍스트** | - | O | O |
| 음량 균일화 | 클립별 게인(±6dB 제한) | O | O | O |
| 숏츠 후보 | 완결된 20~60초 구간 추천 → 9:16 별도 드래프트 | - | O | O |
| 용어 사전 | `틀린표기=맞는표기` 자막 교정, 표기만 쓰면 강조어 | O | O | O |

숏폼은 가로 영상을 1080×1920 캔버스에 중앙 크롭으로 채웁니다. 수요 순위는 반복 수작업 빈도에 대한 설계 판단이며 실측 통계가 아닙니다.

## 영상 대비 개선점
| 개선 | 효과 |
|---|---|
| 컷 건너뛰기 프리뷰 (재인코딩 없음) | 캡컷을 열기 전에 결과를 바로 들어볼 수 있음 |
| 컷별 토글 + `[` `]` 보존 마킹 → **ASR 재실행 없이** 드래프트 재생성 | 수정 1회 ≈ 1초 |
| 배경 소음 기반 **적응형 무음 임계값** | 고정 dB 오탐 감소 |
| 컷 경계 **숨쉬기 여유**(0.12s) + 0.35s 미만 파편 제거 | 로봇같은 컷·소리 파편 방지 |
| ffmpeg PCM을 ASR에 직접 전달 | PyAV 버전 충돌 제거, 이중 디코딩 제거 |
| SSE 이벤트 리플레이 | 새로고침/재접속해도 진행 상태 복원 |
| `tm_duration`/`draft_name` 보정 | pycapcut 기본 저장은 길이 0·이름 없음으로 표시됨 |
