# 품질확인서 — 캡컷 에이전트 v0.1.0

공정: 분석 → 설계 → 개발 → 검증 → 피드백. 검증은 개발자 자체 검증이며, 아래 "미검증" 항목은 사용자 확인이 필요합니다.

## 1. 요구사항 적합성

| # | 요구사항 | 구현 | 검증 방법 | 결과 |
|---|---|---|---|---|
| R1 | mp4/mov 입력 → 캡컷 드래프트 출력 | `pipeline` + `draft` (pycapcut) | e2e 테스트: draft_content/meta JSON 구조 확인 | 적합 |
| R2 | 무음 컷 | 적응형 임계 + 숨쉬기 여유 | 합성 영상(발화 0–2s, 4–6s) 구간 검출 오차 <0.15s | 적합 |
| R3 | 잔말·NG 컷 (전체 대본 기준) | `filler.detect` (재촬영 유사도, NG 선언, 필러, 말더듬) | 단위 테스트 4종 | 적합 (합성 대본 기준) |
| R4 | 단어별/세그먼트 자막, 컷 반영 | `subtitles.build` 출력 타임라인 리맵, SRT | 컷된 단어가 자막에서 제외됨을 확인 | 적합 |
| R5 | FastAPI + 정적 HTML 1장 | `server.py`, `web/index.html` | 브라우저(Chromium) 구동, 콘솔 오류 0건 | 적합 |
| R6 | SSE stepper, 완료 카드 | 4단계 stepper, 결과 화면 | e2e: 단계 순서 silence→asr→filler→draft | 적합 |
| R7 | ASR 직렬화 / content-hash 캐시 | `AsrService` Lock + sha256(head+tail+size) | 동일 영상 2회 업로드 → ASR 1회 호출 | 적합 |
| R8 | OS 감지 + 환경 점검 | `env.check`, 상단 칩 | `/api/env` 테스트, UI 칩 표시 | 적합 |
| R9 | 디자인 톤 (다크 #0a0a0a, 카드 #161616, 그린 단일 액센트, 그라데이션/좌측띠/큰 ✓/박스중첩 금지) | `index.html` | 스크린샷 육안 점검, 결함 1건 수정(통계 구분선) | 적합 |
| R10 | 단축키 `[` `]` 보존 마킹 | 키 핸들러 + 서버 `keep_marks` | Playwright로 마킹 → 서버 재빌드 반영 | 적합 |

## 2. 테스트 결과
- 자동 테스트 **15/15 통과** (`python -m pytest -q`, 단위 7 + 통합 8).
- 드래프트 무결성: 타임라인 갭 없음, `tm_duration == draft_content.duration`, 이름 보정 확인.
- UI 실동작(Chromium): 업로드 → stepper → 결과, 컷 토글 → 갱신(ASR 재호출 없음), 컷 건너뛰기 재생(2.5s→4.4s 점프 / OFF 시 미점프), 모바일 폭(390px) 가로 스크롤 없음.
- 오류 경로: 잘못된 확장자 400, 없는 작업 404, 손상 파일/무음 영상 → 원인 메시지 표시.

## 3. 검증 중 발견·수정한 결함
| 결함 | 원인 | 조치 |
|---|---|---|
| NG 컷 옆에 0.2초 소리 파편 잔존 | 숨쉬기 여유가 고립 조각으로 남음 | 고립 조각 최소 길이 0.2→0.35s |

| 통계 숫자 밑에 불필요한 세로선 | CSS 셀렉터가 중첩 div에 적용 | `.stats>div`로 한정 |
| favicon 404 | 미제공 | 인라인 SVG |
| pycapcut 드래프트 길이 0 / 이름 없음 | 라이브러리 기본 저장 | 저장 후 메타 보정 |

## 4. 미검증 · 한계 (정직한 공시)
1. **캡컷 앱에서의 실제 열림/재생** — 샌드박스에 CapCut이 없어 미검증. 사용자가 직접 재생해 확인해야 합니다(핵심 원칙: 빌드 성공 ≠ 검증).
2. **실제 한국어 음성의 ASR 정확도 / 단어 타임스탬프 정밀도** — 합성 톤 영상과 모의 대본으로 검증. faster-whisper(tiny) 구동·모델 로딩은 실제 확인, 한국어 인식 품질은 미확인.
3. **NG 판정 임계값**(유사도 0.6, 간격 20s)은 경험치 기반 초기값 — 실제 영상으로 튜닝 필요. 오탐 시 컷 목록에서 1클릭으로 복원 가능.
4. **mlx-whisper(트랙 A)** 경로는 코드만 작성, 이 환경(Linux)에서 실행 불가로 미검증.
5. 브라우저 프리뷰는 브라우저가 디코딩 가능한 코덱만 재생(H.264 mp4/mov는 Chrome/Safari 일반적으로 가능, 이 환경은 VP9로만 확인).
6. 자막 폰트·스타일은 캡컷 기본 폰트 사용(한글 폰트 지정 미구현).

## 5. 판정
**조건부 적합.** 코어 파이프라인·드래프트 생성·UI는 자체 검증 기준을 충족. 위 4장의 1~4번은 실제 영상으로 사용자 확인 후 최종 합격 처리 권장.
