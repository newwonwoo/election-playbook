## 5. 미검증 · 한계 (정직한 공시)
0-3. **(v0.6) Clef-omni 연동**
   - **실제 Clef-omni API를 호출해 보지 못했습니다.** 공식 스키마(입력·출력 JSON 스키마 파일)를 읽고 그대로 구현했고 가짜 서버로 검증했지만, 실제 서비스의 동작·응답 지연·오류 형태는 다를 수 있습니다. 첫 사용 때 설정 창의 **'연결 테스트'** 부터 눌러 확인하세요.
   - **AI 판단의 정확도는 모릅니다.** Cloudflare의 성능 수치는 자체 보고이고 오디오·영상 벤치마크는 공개되지 않았습니다. "얼굴이 어디 있나", "흔들리나" 같은 질문에 얼마나 맞게 답하는지, 확률이 보정돼 있는지 확인하지 못했습니다. 그래서 **AI 제안 컷은 기본이 꺼진 제안**입니다.
   - 얼굴 위치는 **5구간 분류**(맨 왼쪽/왼쪽/가운데/오른쪽/맨 오른쪽)라서 정밀하지 않습니다. 합성 영상에서 세로 화면의 정중앙에서 약 ±0.1 벗어났습니다. 여러 사람이 있거나 얼굴이 작으면 더 틀릴 수 있습니다.
   - **영상 조각이 Cloudflare로 전송됩니다**(8초 단위, 480p, 소리 포함). 기본 꺼짐, 켤 때 확인 창이 뜨지만 회사·고객 정보가 담긴 영상은 쓰기 전에 판단이 필요합니다. 대본·자막 글자는 보내지 않습니다.
   - **비용은 문서의 가격(입력 100만 토큰당 $0.15)과 토큰 환산으로 계산한 추정**입니다. 실제 청구액은 다를 수 있습니다(영상 1분 약 $0.002).
   - **레퍼 스타일 변환 규칙은 제가 정한 경험칙**입니다(예: 분당 컷 12회 이상 → 줌 켬, 큰 자막 50% 이상 → 자막 크게). 값마다 근거를 보여주지만 '이 레퍼와 같은 느낌이 나는지'는 검증하지 못했습니다.
   - 컷 속도는 장면 전환 감지(임계값 0.15)로 셉니다. 실제 점프컷이 화면 변화가 작으면 덜 세질 수 있고, 움직임이 큰 영상은 더 세질 수 있습니다.
   - 레퍼 '찾기'는 **내가 넣어 둔 영상 안에서만** 합니다. Clef-omni는 인터넷을 검색하지 못하고, 유튜브 영상을 내려받는 기능은 만들지 않았습니다.
   - 레퍼 스타일에서 **자막 글꼴·색·위치, 효과음, B-roll, 장면 전환**은 반영하지 못합니다(우리가 만들 수 없는 요소). 컷 감도(무음·여유)는 새 작업에만 적용되고, 이미 끝난 작업에 스타일을 입힐 때는 바뀌지 않습니다.
   - 같은 장면이 여러 개 있을 때 '더 좋은 테이크'를 AI로 고르는 기능은 없습니다(NG 판정은 여전히 '마지막 테이크 유지').

   - 영상을 한 번 다시 인코딩하므로(CRF 20) 원본 화질과 완전히 같지는 않습니다.
   - 수십 분짜리 긴 영상은 청크 경로를 소규모로만 검증했고, 실제 장시간 영상은 시도하지 않았습니다.
   - 완성본을 브라우저에서 바로 재생하는 것은 브라우저의 H.264 지원에 달려 있습니다(이 환경의 Chromium은 H.264 미지원이라 재생은 못 보고, 파일 정보·프레임 추출·다운로드로 확인).
1. **캡컷 앱에서 열림/재생** 미검증(샌드박스에 없음). 사용자가 직접 재생해 확인하세요. 특히 줌·팝업·애니메이션이 의도대로 보이는지.
2. **실제 한국어 음성**에서의 탐지 정확도 미검증. 훅·챕터·강조는 규칙 기반 휴리스틱이라 영상마다 오탐/누락이 있을 수 있고, 모두 포인트 탭에서 끌 수 있습니다. 임계값은 초기값입니다.
3. **강조 팝업 등장 애니메이션**은 pycapcut 열거값(`向上弹入`)을 쓰며, 국제판 캡컷에 없으면 효과 없이 텍스트만 표시될 수 있습니다(드래프트는 유지).
4. 줌은 화면 **중앙 기준**(얼굴 추적 없음). 숏폼 크롭도 중앙 고정이라 인물이 치우친 영상은 어긋날 수 있습니다.
5. 챕터 제목은 키워드 2개 조합(LLM 요약 아님). 영상이 최소 챕터 길이의 2배 미만이면 챕터를 만들지 않습니다.
6. **미구현**: 효과음(SFX), 화면 전환 효과, 속도 조절(말 느린 구간 가속), 입소리·호흡 제거, 부분 색상 자막(pycapcut 미지원).
7. 브라우저 프리뷰는 원본 기준이라 훅 티저는 재생되지 않습니다(드래프트에는 포함).
8. v0.1 미검증 항목(mlx-whisper 트랙, 실제 ASR 품질 등)은 그대로입니다.

## 6. 판정
**조건부 적합.** 편집 포인트 7종의 자동 편집·UI·드래프트 반영은 자체 검증 기준을 충족. 5장 1~2번은 실제 영상으로 확인 후 최종 합격 처리 권장.
