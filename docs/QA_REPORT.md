# SKY RUSH 품질확인서

- 작성일: 2026-09-29
- 대상: 3D 빗자루 비행 액션 게임 (Three.js + Vite), 참고 영상 기반
- 실행: `npm install && npm run dev` → 브라우저 접속 / 배포용 `npm run build` (dist/, 상대경로 base)

## 1. 요구사항 분석 (참고 영상 → 요구사항)

| # | 요구사항 | 영상에서 확인한 요소 |
|---|---|---|
| R1 | 3D 공간 비행 | 3인칭 후방 추적 카메라, 빗자루 탄 캐릭터(빨간 망토·주황 모자) |
| R2 | 실제로 날아다니는 느낌 | 저공 흙길 비행, 뱅킹(기울기), 부유섬·절벽·바다, 비행선·구름 |
| R3 | 속도감 | 강한 방사형 모션블러, 스피드라인, 가장자리 번짐 |
| R4 | 타격감 | 링 통과 이펙트, 조준 원형 레티클, 파편 |
| R5 | 게임성 | 링·아치·장애물·적이 있는 코스 |

## 2. 설계 요약

| 모듈 | 파일 | 역할 |
|---|---|---|
| 월드 | `src/world.js` | 노이즈 지형 무한 청크 스트리밍(9×9), 흙길·절벽·바다, 나무/바위/풀/아치/크리스탈/부유섬, 하늘·구름·비행선 |
| 플레이어 | `src/player.js` | 빗자루 라이더 모델, 망토 물리 흔들림, 요/피치/롤 아케이드 비행, 부스트·급강하 가속, 지면 충돌 |
| 이펙트 | `src/fx.js` | 파티클·물리 파편·충격파·스피드라인, 후처리(방사블러+색수차+비네팅+플래시), 트라우마 셰이크, 팝업 |
| 엔티티 | `src/entities.js` | 링 체인, 적(바위 파수꾼), 유도 마법탄, 적 탄, 선분-구 충돌 |
| 사운드 | `src/audio.js` | WebAudio 합성(바람·발사·타격·폭발·링 음계) — 외부 파일 없음 |
| 메인 | `src/main.js` | 게임 규칙·점수/콤보·히트스톱/슬로모션·카메라·HUD |

### 속도감 구현
- 속도 연동 방사형 블러 + FOV 68°→88°(+이벤트 킥), 부스트 시 색수차
- 카메라 로컬 스피드라인, 기체 미세 진동, 속도 비례 카메라 거리
- 저공비행(8m 이하) 시 흙먼지/물보라 + 추가 라인 + "LOW FLY" 점수

### 타격감 구현
- **히트스톱**: 명중 45ms / 격파 110ms / 몸통박치기 170ms (시뮬레이션·파티클 정지, 카메라 셰이크는 계속)
- **슬로모션**: 격파 시 0.35초간 시간 28%
- 적 피격: 흰색 플래시 + 스쿼시 펀치 + 넉백 + 스파크 + 미니 충격파 + 저음 "퍽" 사운드
- 격파: 파티클 150개, 지형에 튕기는 물리 파편 26개, 이중 충격파, 화면 플래시, FOV 킥
- 부스트 들이받기: 나무·바위 박살(파편) / 비부스트 충돌은 튕김 + 피해 + 강한 셰이크
- 링: 링 법선 방향 충격파 + 속도 버스트 + 연속 통과 시 음계 상승

## 5. 한계 및 후속 제안
- 샌드박스엔 GPU가 없어 FPS를 측정하지 못함(소프트웨어 렌더링 2~3fps). 실제 PC/모바일에서 프레임을 확인해야 하며, 느리면 `src/main.js`의 `DPR` 값을 1로 낮추면 됨
- 타격 사운드는 합성음이라 실제 효과음 파일을 쓰면 더 좋아짐
- 후속 후보: 보스전, 코스/타임어택 모드, 캐릭터 선택, 게임패드 진동
- 기존 선거 플레이북 코드는 `legacy/`로 옮겨 보관(빌드에는 포함되지 않음)
