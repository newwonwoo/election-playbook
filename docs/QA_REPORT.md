# SKY RUSH 품질확인서 (v2 — 1인칭 추격 슈팅)

- 작성일: 2026-09-29
- 대상: 1인칭 비행 추격 슈팅 + 자동 타겟팅 (Three.js + Vite)
- 실행: `npm install && npm run dev` / 배포 `npm run build` → `dist/`

## 1. 요구사항 분석 (참고 영상 재분석)

v1은 영상을 3인칭 링 레이싱으로 잘못 해석함 → 사용자 피드백("슈팅 자동타겟팅 FPS") 후 프레임별로 다시 분석함.

| # | 요구사항 | 영상 근거 |
|---|---|---|
| R1 | 1인칭 비행 | 카메라가 곧 플레이어, 선회 시 화면 기울어짐 |
| R2 | 도주 표적 추격 | 앞에서 빨간 망토 라이더가 흙길을 따라 지그재그로 도주, 그림자 있음 |
| R3 | 자동 타겟팅 | 원형 레티클이 표적 위에 크게 떴다가 줄어들며 잠김 |
| R4 | 슈팅 타격감 | 노란 구체 탄이 표적에 명중하며 터짐, 갈색 바위 파편 |
| R5 | 속도감 | 방사형 모션블러, 가장자리 번짐, 저공비행 |

## 2. 설계

| 모듈 | 변경 내용 |
|---|---|
| `src/main.js` | 1인칭 카메라(롤·흔들림·FOV), 락온 게이지(시야 원뿔 23°/320m, 0.5초 충전), 락온 시 자동 사격(초당 9발), 수동 사격, 웨이브·시간제한, HUD |
| `src/entities.js` | `Target`: 길 따라 도주, 러버밴드 속도(일반 비행 시 약 120m 거리 유지, 부스트로 따라잡기), 락온되면 회피 기동 증가, 바위 투척, 격추 시 회전 추락→지면 충돌. `Rocks`: 떠다니는 투척 바위. 유도탄 |
| `src/player.js` | 3인칭 모델 제거(표적 모델로 재사용), 비행 물리는 그대로 |
| `index.html` | 타이머, 표적 HP바, LOCK ON 표시, 화면 밖 표적 방향 화살표, 웨이브 배너 |

### 게임 규칙
- 제한시간 60초. 격추 +12초, 아치 통과 +2초, 표적을 놓치면(460m 이상 벌어짐) −8초
- 표적 HP는 20 + 6×웨이브. 웨이브가 오를수록 속도와 바위 투척 빈도 증가
- 바위: 부딪히면 −14 HP / 쏘면 파괴(+50) / 부스트로 들이받으면 박살(무피해)

### 타격감
- 명중: 노란 스파크, 표적 흰색 번쩍임, 흔들림과 넉백, 히트스톱 0.018초, 미세 화면 흔들림, "-1" 숫자
- 크리티컬(15%, 데미지 3): 큰 폭발, 히트스톱 0.06초, 강한 "쿵" 사운드
- 격추: 파티클 160개, 파편, 이중 충격파, 화면 플래시, 히트스톱 0.14초와 슬로모션 0.5초. 이어서 표적이 연기를 끌며 추락하고 지면에서 한 번 더 폭발
